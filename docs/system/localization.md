### 2.8 Localization-related read model (Phase 3) — **IMPLEMENTED**

- **Статус: реализовано как отдельный read-only доменный модуль `src/lib/localization/`.** Никаких новых таблиц БД и никаких новых вызовов YouTube API — это чистый read-model поверх того, что уже синхронизировал `channel-sync` (таблица `videos`).
- **Ответственность:** сводная таблица локализаций по каналу (какие языки есть/отсутствуют у каждого видео), детальный просмотр одного видео (оригинал + все существующие remote-локали), экспорт в XLSX (две вкладки: Videos, Localizations).
- **Файлы:** `src/lib/localization/{contracts,schemas,services,index,languages}.ts`, `adapters/{store,xlsx}.ts` (генерация workbook'а — тонкая обёртка над общим `src/lib/shared-xlsx/`, см. §2.9u); UI — изначально `src/components/localization-manager.tsx`, **с 2026-09-20 объединён с AI Localization в `src/components/languages-manager.tsx`** (см. §2.9b и `docs/roadmap/plans/LANGUAGES_TAB_MERGE_PLAN.md`); `LocalizationOverviewRow` дополнен полем `lastSyncedAt` (из уже существующего `StoredVideoRecord.lastSyncedAt`) для Studio-стиля колонки «Last modified».

- **macOS system service (IMPLEMENTED on `feature/macos-boot-service`, BL-158, ADR 0032; not yet installed on the Mac):** optional launchd daemon `local.ytom.server` (`/Library/LaunchDaemons`, `UserName` = the owner) so another Mac account can use `http://localhost:3000` without the owner logged in. In service mode a failed idle reset of Live writes is logged (`idle_shutdown.session_end_failed`) and retried at the next check. Names in `scripts/macos/service-env.sh`. **ADR 0044 (2026-10-19):** the idle window no longer resets Live writes; `end-session` only logs.
